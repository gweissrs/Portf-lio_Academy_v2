Descrição

Sobre o projeto

Projeto desenvolvido como solução para a BP — Promotora de Crédito. O sistema foi desenvolvido como atividade prática do curso técnico, trabalhando desde a análise de requisitos até a implementação.

O desenvolvimento abrangeu as etapas de levantamento de requisitos, seleção de tecnologias, construção da arquitetura e implementação das funcionalidades de gerenciamento de crédito.

Análise de requisitos Desenvolvimento de software Gerenciamento de crédito
Processo

Etapas do desenvolvimento

  1. 01
    Análise de requisitos

    Levantamento e documentação dos requisitos funcionais e não funcionais do sistema de crédito.

  2. 02
    Seleção de tecnologias

    Escolha das linguagens de programação, frameworks e bibliotecas adequadas aos requisitos identificados.

  3. 03
    Implementação

    Construção das funcionalidades de gerenciamento de crédito conforme a arquitetura definida.

  4. 04
    Validação

    Testes e verificação dos critérios de qualidade, integridade, usabilidade e segurança da informação.
