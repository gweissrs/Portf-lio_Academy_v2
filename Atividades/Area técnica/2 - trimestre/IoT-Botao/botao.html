Descrição

Sobre o projeto

Atividade que utiliza o Arduino para ler o estado de um botão físico conectado ao pino 4, utilizando o resistor interno pull-up da placa. O código monitora continuamente o estado do botão e exibe o resultado no Monitor Serial.

O projeto demonstra o uso de entrada digital com INPUT_PULLUP, eliminando a necessidade de resistor externo, e introduz a comunicação serial entre Arduino e computador.

Leitura de entrada digital Resistor pull-up interno Monitor Serial
Código-fonte

Código Arduino

#define BUTTON_PIN 4

void setup() {
  Serial.begin(9600);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == LOW) {
    Serial.println("Button is pressed");
  } else {
    Serial.println("Button is not pressed");
  }

  delay(100);
}
Funcionamento

Como o projeto funciona

Descrição detalhada do comportamento do sistema ao pressionar e soltar o botão.

Comportamento

Leitura do botão e saída serial

  1. 01
    Conexão do botão ao pino 4

    O botão é conectado ao pino digital 4 da placa Arduino.

  2. 02
    Resistor pull-up interno (INPUT_PULLUP)

    O resistor interno da placa mantém o pino em nível lógico alto (HIGH) quando o botão está solto, eliminando a necessidade de resistor externo.

  3. 03
    Botão pressionado — LOW

    Quando pressionado, o pino passa para LOW e o programa imprime "Button is pressed" no Monitor Serial.

  4. 04
    Botão solto — HIGH

    Quando solto, o pino retorna para HIGH e o programa imprime "Button is not pressed" no Monitor Serial.

  5. 05
    Leitura a cada 100 ms

    A função delay(100) garante que o estado seja verificado e impresso a cada 100 milissegundos.
