Acender LED

Introdução à programação de microcontroladores com o LED integrado do Arduino.

Descrição

Sobre o projeto

O projeto controla o LED integrado da placa Arduino, alternando entre ligado e desligado em intervalos de um segundo. É a atividade introdutória à programação de microcontroladores, compreendendo o ciclo de execução do Arduino.

Por meio das funções setup() e loop(), o programa configura o pino do LED como saída e o aciona repetidamente em ciclos de 1 segundo.

LED integrado (LED_BUILTIN) Saída digital Temporização com delay
Código-fonte

Código Arduino

void setup()
{
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop()
{
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
Funcionamento

Como o projeto funciona

Descrição do comportamento do LED integrado durante a execução do programa.

Comportamento

Ciclo de execução

O LED integrado da placa é acionado por 1 segundo e apagado por 1 segundo, em loop contínuo. O programa nunca para — enquanto a placa estiver energizada, o ciclo se repete indefinidamente.

  1. 01
    setup() — configuração inicial

    O pino LED_BUILTIN é configurado como saída digital (OUTPUT). Executado uma única vez ao iniciar.

  2. 02
    LED aceso (HIGH)

    O pino recebe nível lógico alto, acendendo o LED por 1000 ms (1 segundo).

  3. 03
    LED apagado (LOW)

    O pino recebe nível lógico baixo, apagando o LED por 1000 ms (1 segundo).

  4. 04
    Repetição contínua

    A função loop() retorna ao início, repetindo o ciclo indefinidamente.
