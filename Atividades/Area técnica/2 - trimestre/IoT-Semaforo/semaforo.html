Semáforo com Arduino

Simulação de semáforo utilizando três LEDs controlados por temporização e lógica de oscilação.

Descrição

Sobre o projeto

Simulação de semáforo utilizando três LEDs — verde (pino 10), amarelo (pino 9) e vermelho (pino 8) — controlados por Arduino com temporização e lógica de oscilação.

O projeto aplica controle de múltiplas saídas digitais, estruturas de repetição e definição de constantes, simulando o comportamento real de um semáforo de trânsito.

Três LEDs (verde, amarelo, vermelho) Saídas digitais múltiplas Estrutura de repetição (for)
Código-fonte

Código Arduino

#define LEDverde 10
#define LEDamarelo 9
#define LEDvermelho 8

void setup()
{
  pinMode(LEDvermelho, OUTPUT);
  pinMode(LEDamarelo, OUTPUT);
  pinMode(LEDverde, OUTPUT);
}

void loop()
{
  digitalWrite(LEDvermelho, LOW);
  digitalWrite(LEDverde, HIGH);
  delay(2000);
  digitalWrite(LEDverde, LOW);
  delay(500);

  for (int i = 0; i < 3; i++){
    digitalWrite(LEDamarelo, HIGH);
    delay(500);
    digitalWrite(LEDamarelo, LOW);
    delay(500);
  }

  digitalWrite(LEDvermelho, HIGH);
  delay(2000);
  digitalWrite(LEDvermelho, LOW);
  delay(500);
}
Funcionamento

Como o semáforo funciona

Descrição detalhada do comportamento de cada LED durante o ciclo do semáforo.

Sequência de estados

Ciclo completo do semáforo

  1. 01
    LED Verde (pino 10) — 2 segundos

    O LED verde acende por 2000 ms. O LED vermelho permanece apagado neste momento.

  2. 02
    Pausa — 500 ms

    O LED verde apaga. Pausa de 500 ms antes do início da oscilação amarela.

  3. 03
    LED Amarelo (pino 9) — 3 oscilações

    O LED amarelo oscila 3 vezes: 500 ms ligado, 500 ms desligado, usando estrutura for.

  4. 04
    LED Vermelho (pino 8) — 2 segundos

    O LED vermelho acende por 2000 ms. Após 500 ms de pausa, o ciclo reinicia.

  • Oscilação controlada por iterações
